# AeroTwin development instructions

- Preserve honest provenance and fixed synthetic epochs. Live errors never substitute synthetic positions under a LIVE badge.
- Runtime is local-only and keyless. Do not add telemetry, hosted databases, LLMs or required credentials.
- Only pre-issuance features enter models. Keep temporal label embargoes and measured baselines.
- Keep queues and propagation assumptions inspectable; never claim operational certification or identified causal effects.
- Run `python -m pytest -q`, `ruff check backend tests/backend scripts`, frontend test/build, and Playwright with both local servers.
- Generated models, official imports and observed ADS-B data stay out of Git.
