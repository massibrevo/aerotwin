# UX and mode semantics

Eight durable routes share a local sidebar and a historical dataset selector. Navy/slate surfaces, restrained cyan and amber data-class badges distinguish layers. System fonts, labeled native controls, focus styles, keyboard aircraft selection, loading/error/empty states and responsive stacked layouts support usability. No formal accessibility certification is claimed.

First launch is always offline synthetic demo. Users explicitly enable live positions or online map tiles. A provider error remains LIVE-unavailable, with an explanatory message and empty positions. Offline map is bundled public-domain geometry. Online map is optional MapLibre/OpenFreeMap; errors/timeouts return to offline geometry. Track rotates aircraft; list/map use the same filters. No interpolation is claimed.

Replay uses a fixed BCN synthetic recording independently of the chosen region. History date/search/origin filters affect table and export; charts explicitly summarize the full dataset. Radar mode/geography and historical dataset/model are independent layers. Schedule counts, aircraft observations and hypothetical queue results must never be conflated.
