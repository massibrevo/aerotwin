# Architecture

React/TypeScript → Vite same-origin `/api` proxy → local FastAPI on port 8000. Durable UI routes: `/`, `/radar`, `/pulse`, `/history`, `/forecast`, `/network`, `/data`, `/about`. The app binds to localhost, with no account, external backend or telemetry. Frontend interfaces and Pydantic/OpenAPI describe the same JSON contract; automatic client generation is future work.

- `data/store.py`: seeded examples, strict BTS mapping/timezones, typed Parquet snapshot and provenance, parameterized DuckDB filters. Single-file storage is intentional for this small-data release; monthly partitions are future work.
- `providers/aircraft.py`: typed normalization, shared geographic 30s cache, global async lock and minimum 1.1s request spacing, 10s timeout, bounded 32-region cache and exponential failure cooldown. Numeric 429 Retry-After is clamped to 30–600s; date-form values use a 60s fallback. Live errors always return empty positions, never disguised synthetic fallback.
- `ml/engine.py`: feature allowlist, temporal embargo, baseline/ML fitting, validation selection, residual intervals, measured metrics, expanding-origin checks and fixed-path saved artifacts.
- `simulation/engine.py`: directed route counts/centralities and paired SimPy queues. API serializes simulation calls and offloads CPU work. Latest 50 runs are retained in memory; restart clears them.

## Interfaces

Open `/docs` for full schemas. `GET /api/v1/aircraft` accepts mode, lat/lon, radius (1–250 nautical miles) and frame. It returns source/status, actual receipt UTC, position UTC/age and original ft/kt units with null altitude preserved. `GET /aircraft/stream` emits SSE `event: snapshot` plus JSON `data` every 30s, ending on disconnect. UI uses cancellable JSON polling, pauses with hidden tabs, and explicitly selects live mode. SSE consumers should close inactive streams and reconnect with bounded backoff.

Historical endpoints use dataset, search/origin/date filters and pagination. CSV export matches filters, max 500 rows. Aggregate charts intentionally use the full loaded dataset and are labeled accordingly. Prediction accepts only fixed model IDs and schedule inputs. Simulation accepts airport, reduction 0–0.7, duration 15–360min, repetitions 1–100, seed and dataset; GET by returned ID retrieves the session result.

CORS is an explicit local allowlist; the same-origin proxy supports alternative local UI ports without broadening it. No arbitrary URL fetch, uploaded model deserialization, API filesystem paths or interpolated SQL values. Joblib loads only artifacts generated by the local fixed-ID training commands. Never supply untrusted pickles. Do not expose this unauthenticated development app publicly or run multiple provider workers to bypass limits.
