# Architecture — 0.2

Normal distribution: compiled React/TypeScript + FastAPI from one loopback origin, port 5188 by default. `scripts/serve.py` verifies prerequisites/port, launches one Uvicorn worker, probes readiness and handles shutdown. No Node process is used at runtime. `web.py` serves an allowlisted set of SPA routes plus static assets; missing API/asset paths return 404 rather than SPA HTML. Development still supports separate Vite/API servers.

`AEROTWIN_HOME` selects the writable state root (default source root). Imports, models and SQLite history live there. A ZIP contains source, compiled assets, seeded examples, docs and an internal SHA-256 manifest; no private imports, observed positions, model pickles, caches, virtual environments or credentials. It still requires a supported Python and first-setup package downloads.

`data/store.py` validates BTS CSV fields, timezone normalization and duplicates. Each import writes immutable `year=YYYY/month=MM` Parquet partitions under a unique snapshot ID. Only after all partitions succeed does an atomic `current.json` replacement activate the snapshot and its provenance together. Legacy single-file snapshots remain readable. Imports replace the active dataset, not append. Historical count/filter/pagination uses DuckDB parquet scans and SQL LIMIT/OFFSET rather than Python materialization of all matches. Aggregate analysis/training still loads full frames, so reasonable local dataset sizes matter.

`ml/engine.py` retains temporal labels/splits, baseline comparison, validation-selected regression and empirical intervals. It adds train-support metadata, subgroup errors, source revision and sklearn version. Artifacts use unique names with SHA-256; one atomic report manifest publishes the chosen version. Prediction rejects changed data revisions, incompatible sklearn versions, damaged artifacts and airports/carriers not present in train. Checksums detect accidental damage, not malicious replacement: never deserialize untrusted model files. Older artifacts are retained, not automatically collected.

`storage.py` uses a local transactional SQLite WAL ledger with closed per-operation connections. Imports, training reports, job state and simulation results survive restarts. `jobs.py` allows one browser training/import operation at a time; CPU training runs in a worker thread and persists queued/running/succeeded/failed states. Startup marks interrupted jobs failed. CLI operations are explicit local commands; do not run concurrent CLI writers against the same state. Model training detects dataset revision changes before publication.

Provider protocol, response validation, bounded shared cache, 30s TTL, timeout/cooldown and explicit live failure semantics remain. Missing/nonfinite position age is rejected instead of fabricated as fresh. SSE emits `event: snapshot` with JSON every 30s and cancels on disconnect; the UI uses cancellable JSON polling and pauses hidden tabs. No global background scraping or implicit live source fallback.

Security boundary: loopback bind, trusted Host allowlist, external-origin write rejection, explicit local CORS, bounded raw CSV import (20MiB), no user-provided fetch URLs or filesystem paths, no model uploads, bounded simulation controls, parameterized SQL, extra JSON fields rejected, defensive response headers. There is no multiuser authentication or public-hosting threat model. No public exposure is configured.

API reference: `/docs` and `/openapi.json`. New endpoints: `GET /api/v1/ready`, `POST /data/import-bts` (raw CSV body, JSON timezone map query), `POST /models/train`, `GET /jobs/{id}`, `GET /experiments`, `GET /data/datasets/{dataset}`. All are prefixed `/api/v1`. Readiness verifies the demo data/model revision and artifact hash; health is liveness. Simulation IDs retrieve persistent ledger entries. Browser import does not independently authenticate a CSV's source.
